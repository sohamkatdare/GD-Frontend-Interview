You are tasked with building a React component based on [this Figma design](https://www.figma.com/design/GEawihhiNgqeMa8Qay9Bhg/GD-Frontend-Interview?node-id=0-1&t=VKOosreNNekXtKb5-1). The design shows a simple UI with an image on the left, and on the right side, there is a headline, description, a horizontal line, and a button that will redirect the user to [this link](https://www.gd.com/about-gd).  

## Setup Instructions:
- Clone this repository onto your local machine and navigate to project directory
- Install dependencies (npm install)
- Set up development server (npm start)

## Requirements: 
- Open the Healthcare.tsx file located in the src directory of the project
- Implement the UI as specified in the Figma design in the Healthcare React component. 
- Use the healthcare.css file to style the elements and try to match them to the Figma styles as best as you can
- Implement using the image from the Figma
  - Double-click on the image
  - Right-click
  - Choose “Copy/Paste as” and then select “SVG” from the options
  - Paste the copied SVG code into the appropriate location in your React component
- Make sure that the clickable ‘Learn more’ button will redirect to the link given above

Start the development server using “npm start”. This will open the project in your default web browser at [this url](https://localhost:3000), allowing you to view and test your changes.
